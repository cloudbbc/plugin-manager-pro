Plugin Manager Pro

> 🚀 Blender 4.5+ 高级插件管理器 — 按需加载，释放系统资源

## 为什么需要 Plugin Manager Pro？

Blender 安装的插件越多，启动时自动加载的插件也越多。大量插件在后台持续运行，即使你当前根本用不到它们，也在不断消耗着内存和 CPU 资源。这会导致：

- 🐌 **Blender 启动变慢** — 每个自启插件都要在启动时初始化
- 💾 **内存占用攀升** — 插件即使闲置也常驻内存
- ⚠️ **插件冲突频发** — 加载的插件越多，冲突概率越高
- 🔋 **整体性能下降** — 后台插件可能持续消耗计算资源

**Plugin Manager Pro 的核心理念：用哪个，加载哪个。** 让不需要的插件保持停用状态，只在需要时一键加载，从根源上降低资源消耗。

## 核心功能

### 🎯 分类管理 — 按工作场景组织插件

将插件按工作场景归类管理，一目了然：

| 分类 | 适用场景 |
|------|----------|
| 3D视图 | 建模、动画、场景等通用插件 |
| 网格编辑 | 网格建模、拓扑、曲线等 |
| 雕刻模式 | 雕刻笔刷、细节工具 |
| 姿态模式 | 骨骼绑定、蒙皮 |
| UV纹理 | UV展开、纹理绘制 |
| 着色器模式 | 材质节点、着色器编辑 |
| 几何节点模式 | 几何节点相关工具 |
| 合成器模式 | 后期合成、特效 |
| 图像 | 图像编辑、纹理处理 |
| 视频编辑 | 剪辑、序列器 |
| 系统插件 | 导入/导出、渲染引擎、物理模拟 |

- 支持**自定义分类**，按你的工作流自由组织
- 每个分类可自定义**图标和名称**
- 插件可同时归属**多个分类**
- 分类排序可自由调整

### ⚡ 按需加载 — 一键启用/停用

- **Header 快捷入口**：3D 视口标题栏右侧直接显示分类图标，点击即可弹出该分类下的插件列表
- **一键加载**：点击即可在当前会话中启用插件，立即生效
- **一键停用**：不需要时随时停用，立即释放资源
- 不影响 Blender 的扩展系统，停用的插件可随时重新加载

### 🔒 启动控制 — 精确管理自启

- 每个插件可独立设置**是否随 Blender 自启**
- 首次使用时自动同步当前已启用插件的状态
- 仅标记为自启的插件才会在启动时加载，其余保持停用
- 自启状态与 Blender 原生设置同步，不冲突

### 🔍 快速搜索与过滤

- **实时搜索**：按插件名称或模块名即时过滤
- **分类过滤**：点击分类图标只显示该分类下的插件
- **未分类过滤**：快速找到尚未归类的插件

### ✅ 批量操作 — 高效管理

- **多选插件**：勾选多个插件进行批量操作
- **批量设置分类**：一键为多个插件分配或移除分类
- **批量切换自启**：一键开启或关闭多个插件的自启状态
- **批量取消分类**：快速将选中插件重置为未分类

### 🎨 图标选择器

- 从 Blender 运行时所有可用图标中选择
- 按前缀自动分组（修改器、约束、力场、节点等）
- 网格展示 + 名称输入，快速定位目标图标
- 为每个分类设置专属图标，视觉识别更高效

## 使用场景

### 场景一：建模师
只保留建模相关的插件为自启（网格编辑、3D视图），雕刻、UV、动画类插件按需加载。启动速度提升，内存占用显著降低。

### 场景二：动画师
仅启用姿态模式和3D视图相关插件，渲染、合成类插件需要时再加载。避免无关插件干扰工作流。

### 场景三：通用用户
安装了大量插件但日常只用少数几个。将常用插件设为自启，其余全部按需加载。Blender 启动快如闪电。
